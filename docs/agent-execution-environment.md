# Agent 执行环境

Pine 的普通 shell 是具备明确数据边界的本地开发环境。策略集中在
`apps/desktop/src/agent/bash-sandbox.ts`，环境变量集中在 `bash-env.ts`。
不要按失败命令不断新增工具专属绕行逻辑。

## 能力划分

- **项目数据**：共享目录遵守读写授权；附件默认只读；未共享文件内容仍需审批。
- **路径发现**：已授权路径的祖先目录允许列举，以支持运行时向上发现工作区。
  literal 目录规则不会授权兄弟文件内容或对子目录的递归访问。
  这意味着模型可能看到祖先目录中的文件名；不是隐藏所有文件名的隔离模型。
- **运行环境**：系统库、应用安装目录、开发工具、框架、系统级配置和工具选择目录只读。
  不为单个 Python/Xcode 版本增加启动器绕行，也不把整个 `/System`、用户 HOME
  或任意 PATH 目录视为隐式读取授权。
- **临时存储**：项目临时目录供 shell、子进程和文件工具共用。macOS 的用户临时目录
  也属于运行环境，可读写；系统服务可能用原生 API 定位它而不遵循 TMPDIR。
  该目录可能含其他应用的临时数据，因此它不是项目间隔离的存储。
  不开放全局 `/tmp`，非 macOS 或不在 `/private/var/folders` 下的回退值不隐式授权。
- **原生能力**：应用控制、外部文件操作等使用现有审批工具。普通 bash 不自动重放失败命令，
  因为命令失败前可能已产生部分副作用。

## 环境契约

保留实际 HOME 和登录 PATH，传入最小环境变量集合；不隐式开放用户配置和凭据。
TMPDIR 指向项目临时目录，zsh 的 TMPPREFIX 同样指向其中，保证 here-doc 正常工作。
缓存变量也指向项目临时目录。命令描述直接提供临时目录绝对路径，路径可能含空格。

平台兼容适配（例如 zsh 使用 TMPPREFIX）是合理的，但必须位于统一环境配置中，
不能要求模型在每个任务中重新发现。新增权限应对应可解释的运行环境类别，并同时验证
真实工具行为和未共享数据边界；不要仅靠 profile 字符串快照。

## 2026-09-04 会话回归

本地“把尖锐角落搞成微圆角”会话出现 here-doc 拒绝，以及 shell 中 TMPDIR 存在、
Bun 中整个环境表却为空，随后模型全盘搜索输出文件并反复修改脚本。

- zsh 的 here-doc 默认使用 `/tmp/zsh…`，仅设置 TMPDIR 不足。
- Bun 1.3.4 在加载进程环境前读取工作目录信息；禁止祖先目录列举会使该阶段提前返回。
  修复路径发现能力，而非给 Bun 注入第二份环境或更换运行时。
- 系统开发工具启动器需要完整应用包、系统配置、工具选择目录和原生临时存储。
  单独允许 Xcode 的 Developer 子目录是不完整的运行环境模型。

原生回归包含空格路径、here-doc → Bun → TMPDIR 文件落盘、系统 Python 启动，
以及祖先目录可列举但兄弟文件不可读、只读目录不可写、符号链接不能越界。
外层沙箱不能嵌套 Seatbelt，相关测试需在允许启动 Pine 自身沙箱的环境运行。
